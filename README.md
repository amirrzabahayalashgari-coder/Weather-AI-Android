# هواشناسی هوشمند اندروید

اپلیکیشن بومی اندروید با رابط فارسی و راست‌چین؛ بدون WebView.

## امکانات
- جستجوی شهر
- نمایش دمای فعلی و دمای احساسی
- رطوبت، سرعت باد، فشار و بارش
- پیش‌بینی هفت‌روزه و شاخص UV
- دریافت اطلاعات از سرویس Open-Meteo

## ساخت APK
با هر بار Push به شاخه main، GitHub Actions فایل APK نسخه Debug را می‌سازد.
برای دریافت فایل: مخزن را باز کنید، وارد Actions شوید، آخرین اجرای موفق Build Android APK را انتخاب کنید و از بخش Artifacts فایل Weather-AI-debug-apk را دانلود کنید.

## نیازمندی‌ها
- Android 6.0 یا بالاتر
- اتصال اینترنت برای دریافت داده‌های هواشناسی
